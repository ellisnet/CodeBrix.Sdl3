WHAT THIS FOLDER IS
--------------------------------------------------------------------------------
An unmodified snapshot of the upstream SDL (Simple DirectMedia Layer) source
tree. It is the ONLY source the SDL3 native libraries in this repository are
ever built from. No build step in this repository clones, downloads, or
otherwise fetches SDL (or anything else) at build time - see ../README.txt for
the rule this exists to satisfy.

THIS IS NOT A TAGGED SDL RELEASE - AND WHY
--------------------------------------------------------------------------------
3.5.0 is SDL's in-development version number on the main branch at this commit;
there is no release-3.5.0 tag behind it. The commit is chosen deliberately: it
is exactly the SDL commit that the ppy/SDL3-CS 2026.722.0 release pins as its
External/SDL submodule - the commit its C# bindings were GENERATED from and its
prebuilt native binaries were BUILT from. CodeBrix.Sdl3's managed bindings are
ported from that release, so building the natives from this same commit means
the bindings, this source and every shipped native describe one C API. A tagged
release would be a different API surface from the one the bindings declare.

When the bindings are regenerated against a newer SDL, this snapshot is
replaced as a whole by a new one, this file is rewritten, and every native is
rebuilt - never a partial update.

~/GitHome/SDL3-CS checkout (ppy/SDL3-CS at tag 2026.722.0; the submodule
initialized shallow at the pinned commit the same day), with exactly this

    rsync -a --exclude='/.git' \
        /home/jeremy/GitHome/SDL3-CS/External/SDL/ \
        /home/jeremy/GitHome/CodeBrix.Sdl3/sdl3-native-tools/SDL/

and this identity check of the source, run before copying:

    $ git -C ~/GitHome/SDL3-CS/External/SDL rev-parse HEAD
    a8591d943b7079b17fdd018dc04ec9c71dc94ae4

Everything in the upstream working tree was copied EXCEPT the .git entry (in a
submodule checkout that is a one-line gitdir pointer file). There were no build
directories in the checkout, so nothing else was skipped. 2307 files, about
59 MB, equal to `git ls-files | wc -l` of the upstream checkout. The upstream
android-project/, VisualC/, VisualC-GDK/, Xcode/, build-scripts/, cmake/,
docs/, examples/, include/, src/, test/ and wayland-protocols/ are all present,
so the snapshot is a complete upstream tree and not a subset. (The Android
bridge jar is built from android-project/'s Java sources; SDL's own Wayland
protocol XML lives in wayland-protocols/.)

After the copy, `diff -r -x .git <source> <this folder>` reported no
differences.

NOT MODIFIED
--------------------------------------------------------------------------------
No file in this folder has been modified, renamed, reformatted or deleted, and
none ever should be. This file (UPSTREAM.txt) is the ONLY addition, and it is a
new file, not an edit of an upstream one.

If a future build ever needs a change to this source, it goes in
../patches/*.patch and is applied by the build scripts into a scratch copy at
build time, never into this folder. As of 2026-10-01 there are no patches.

    git ls-files --others --ignored --exclude-standard -- sdl3-native-tools
        -> should print nothing once they are tracked

NOTHING IN THE SDL BUILD FETCHES
--------------------------------------------------------------------------------
SDL's CMake build has no download step: no FetchContent, no ExternalProject, no
submodules. Every optional dependency is detected on the build machine
(headers via pkg-config / find_package) and, with SDL_DEPS_SHARED=ON, loaded
with dlopen() at run time on the user's machine. The Linux container build
proves this on every run by building with no network interface.

depends on it, and the build works with no network at all.
