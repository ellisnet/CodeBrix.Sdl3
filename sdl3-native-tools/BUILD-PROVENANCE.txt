WHY THIS FILE EXISTS
--------------------------------------------------------------------------------
A binary in a package is anonymous. This file is how anyone later can tell which
native library came from which source, which toolchain and which build machine -
without which "rebuild it and see if it matches" is not a question that can even
be asked. Every time a binary is adopted into ../native_libraries/<rid>/, its
section here is updated from that build's output/<rid>/BUILD-INFO.txt (and the
<file>.provenance.txt beside the binary is written from the same values).

Linux (the three linux-* entries)
--------------------------------------------------------------------------------
  Route           : linux/build.sh <arch> -> container-build.sh, inside
                    codebrix-sdl3-build-<arch> (Containerfile.<arch>: the
                    digest-pinned manylinux base + cmake 4.4.3 + ninja 1.13.2 +
                    SDL's backend -devel headers), run with --network none
  cmake options   : -G Ninja -DCMAKE_BUILD_TYPE=Release -DSDL_SHARED=ON
                    -DSDL_STATIC=OFF -DSDL_TEST_LIBRARY=OFF -DSDL_TESTS=OFF
                    -DSDL_EXAMPLES=OFF -DSDL_INSTALL=OFF -DSDL_DEPS_SHARED=ON
                    -DSDL_RPATH=OFF -DSDL_REVISION=SDL-3.5.0-a8591d9
                    + per-architecture SDL_CMAKE_OPTIONS_<ARCH>: x64 and arm64
                    -DDECOR_0_LIB=libdecor-0.so.0 (+ the vendored libdecor
                    pkg-config folder on PKG_CONFIG_PATH); riscv64
                    -DSDL_X11_XSCRNSAVER=OFF
                    CMAKE_C_FLAGS="-g -ffile-prefix-map=<src>=SDL
                    -ffile-prefix-map=<build>=build -ffile-prefix-map=/work=
                    sdl3-native-tools"; linker -Wl,--build-id=sha1;
                    then strip --strip-unneeded
                    (ppy's CI for the same commit: -GNinja, Release,
                    SDL_SHARED=ON, SDL_STATIC=OFF on ubuntu-22.04)
  Backends        : every windowing / audio / input library is dlopen()ed at run
                    time (SDL_DEPS_SHARED=ON); the build only needs its headers.
                    WHICH backends are compiled in therefore depends on the
                    headers each image's repositories carry, and differs by RID -
                    recorded under each RID below, never silent.
  Vendored header : linux/vendored-headers/libdecor-0/libdecor.h - libdecor 0.2.2,
                    MIT, unmodified, sha256 bb85696fea29eea7f7c78cdddacbc02e
                    6234a0ac94f5d331e7f36eedb5f52cfa (see its UPSTREAM.txt), with
                    a pkg-config stub; used by linux-x64 and linux-arm64 only,
                    whose AlmaLinux 8 images have no libdecor-devel. Header only:
                    libdecor is dlopen()ed, never linked.
  Reproducibility : linux-x64 (with the vendored header) was built from scratch
                    THREE times on 2026-10-01 (runs A, B, C; C with the final
                    scripts): stripped and unstripped files byte-identical every
                    time. arm64 and riscv64 were built once each (emulated).
  Gate            : linux/README.txt, THE VERIFICATION GATE (9 checks: ELF,
                    SONAME, RPATH/TEXTREL, exports, NEEDED + ldd -r, glibc
                    floor, build-id, ../smoke-test.c against the stripped file,
                    must-have backend sonames)

BACKEND DIFFERENCES BETWEEN THE LINUX RIDS (recorded, rulings of 2026-10-01)
--------------------------------------------------------------------------------
  * libdecor (Wayland client-side decorations): ON for all three Linux RIDs -
    x64/arm64 through the vendored header (ruling: GO on vendoring it), riscv64
    from its image's libdecor-devel 0.2.2.
  * PipeWire: ON for riscv64 only. x64/arm64 stay OFF by ruling: EL8's
    pipewire-devel 0.3.6 is older than SDL's >= 0.3.44 floor, and audio still
    reaches PipeWire through its PulseAudio layer (pipewire-pulse).
  * sndio: OFF everywhere (not packaged in any image).
  * liburing: ON for riscv64 only (EL8's 1.0.7 has no liburing-ffi); SDL's
    async I/O otherwise uses its thread pool.
  * XScreenSaver extension: OFF for riscv64 only (RHEL 10 has no
    libXScrnSaver-devel); SDL_DisableScreenSaver() there uses D-Bus.
  ppy's ubuntu-22.04 linux-x64 build of the same commit has libdecor, PipeWire
  and sndio.
