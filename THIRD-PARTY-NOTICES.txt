THIRD-PARTY SOFTWARE NOTICES AND INFORMATION

CodeBrix.Sdl3 is a set of C# bindings for SDL3 (Simple DirectMedia Layer 3),
packaged together with the SDL3 native libraries. The managed bindings are a
port of the ppy/SDL3-CS project (notice 1); most of the binding source is
machine-generated from the SDL3 C headers, and the package redistributes the
SDL3 native libraries and a Java bridge built from SDL's own sources (notice 2).
A small attribute file comes from JetBrains Annotations (notice 3). One public
C header from libdecor is vendored for building the Linux natives and is never
shipped (notice 4).

The notices below record that incorporated material and reproduce each license
as required.

Tools that are used but NOT incorporated: ClangSharp
(ClangSharpPInvokeGenerator, MIT, https://github.com/dotnet/ClangSharp) is the
code generator that tools/sdl3_binding_generation/generate_bindings.py runs to
produce Bindings/ClangSharp/*.g.cs from the SDL3 headers. ClangSharp's own
source is not incorporated; the generated files are derived from the SDL3
headers (notice 2). The one exception is src/CodeBrix.Sdl3/
NativeTypeNameAttribute.cs, the small marker attribute that ClangSharp emits
alongside the bindings it generates (an <auto-generated/> file, carried here as
SDL3-CS carries it - notice 1); ClangSharp is MIT licensed
(Copyright (c) .NET Foundation and Contributors), which is compatible with this
project's MIT license.
The Roslyn packages (Microsoft.CodeAnalysis.*) referenced by the in-repo source
generator, and the test packages, are NuGet dependencies of non-packed
projects; they ship with their own LICENSE and notices.

Jeremy Ellis and contributors license the CodeBrix.Sdl3 project to you under
the terms set forth in the LICENSE file, which is located at the root of this
repository.

2. Simple DirectMedia Layer (SDL3)
   -------------------------------------------------------------------------
   Project:    Simple DirectMedia Layer
   Author:     Sam Lantinga and contributors
   Source:     https://github.com/libsdl-org/SDL
   Snapshot:   commit a8591d943b7079b17fdd018dc04ec9c71dc94ae4 (version header
               3.5.0, a development snapshot - the commit the bindings were
               generated from)
   License:    zlib

   Applies to: CodeBrix.Sdl3

   SDL3 reaches this package in three ways:

     a. GENERATED BINDINGS. src/CodeBrix.Sdl3/Bindings/ClangSharp/*.g.cs are
        machine-translated from the SDL3 public headers and carry SDL's zlib
        notice verbatim at the top of every file. The hand-written binding
        partials in src/CodeBrix.Sdl3/Bindings/ also restate SDL macros and
        constants from those headers.
     b. NATIVE BINARIES. The package REDISTRIBUTES the SDL3 native library in
        binary form, committed under native_libraries/<rid>/ and packed under
        runtimes/<rid>/native/ with SDL's LICENSE.txt beside each copy as
        LICENSE-SDL3.txt:
          runtimes/win-x64/native/SDL3.dll
          runtimes/win-arm64/native/SDL3.dll
          runtimes/osx-x64/native/libSDL3.dylib
          runtimes/osx-arm64/native/libSDL3.dylib
          runtimes/linux-x64/native/libSDL3.so
          runtimes/linux-arm64/native/libSDL3.so
          runtimes/linux-riscv64/native/libSDL3.so
          runtimes/android-x64/native/libSDL3.so
          runtimes/android-arm64/native/libSDL3.so
        Each binary has a .provenance.txt beside it in native_libraries/
        recording how it was built or where it was adopted from, with its
        SHA-256; sdl3-native-tools/BUILD-PROVENANCE.txt has the full record.
        Nothing is downloaded during a build.
     c. JAVA BRIDGE. The net10.0-android assembly embeds SDL3AndroidBridge.jar,
        compiled from the org.libsdl.app Java sources in SDL's android-project
        (SDLActivity and its companions).

   The complete, unmodified SDL source snapshot the binaries and the jar are
   built from is vendored in sdl3-native-tools/SDL (with UPSTREAM.txt); that
   folder is not part of the package.

   Note on the zlib license's third condition, which requires that altered
   source versions be plainly marked: the binaries and the jar are built from
   UNALTERED SDL source (any patch applied by a build is kept in
   sdl3-native-tools/patches and named in BUILD-PROVENANCE.txt). The generated
   bindings are a translation of the headers into C#, marked as such by the
   "C# bindings for Simple DirectMedia Layer" line in their header.
